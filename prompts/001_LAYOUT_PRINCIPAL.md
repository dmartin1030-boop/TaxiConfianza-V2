# Prompt 001 - Layout Principal TaxiConfianza V2

## Objetivo

Crear el layout base de TaxiConfianza V2 que será reutilizado por todas las páginas de la plataforma.

## Tecnologías

- PHP 8+
- HTML5
- CSS3
- Bootstrap 5
- JavaScript Vanilla

## Diseño

Seguir un estilo corporativo moderno similar a Stripe, Notion o Linear.

## Colores

- Fondo principal: #F8F7F4
- Gris claro: #F3F4F6
- Blanco: #FFFFFF
- Dorado suave: #C9A86A
- Texto: #2F2F2F

No utilizar amarillos intensos ni colores saturados.

## Debe incluir

- Sidebar izquierdo fijo
- Header superior
- Área principal de contenido
- Footer
- Responsive
- Componentes reutilizables

## Sidebar

Opciones:

- Dashboard
- Mis Vehículos
- Publicar Oferta
- Oportunidades
- Mi Reputación
- Notificaciones
- Perfil

## Header

Debe contener:

- Logo TaxiConfianza
- Buscador
- Notificaciones
- Perfil del usuario

## Estilo

- Minimalista
- Mucho espacio en blanco
- Tarjetas con sombras suaves
- Bordes redondeados
- Tipografía limpia
- Diseño profesional

## Importante

Todo el proyecto deberá reutilizar este mismo layout.
No crear estilos diferentes para cada página.
