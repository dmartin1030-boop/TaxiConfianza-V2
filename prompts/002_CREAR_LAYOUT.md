# Prompt 002 - Crear Layout Principal TaxiConfianza V2

## Rol

Eres un desarrollador Senior especializado en PHP, Bootstrap 5, HTML5, CSS3 y JavaScript.

## Objetivo

Construir el Layout Principal de TaxiConfianza V2 que será utilizado por TODAS las páginas del sistema.

No desarrollar ninguna funcionalidad de negocio.

Solo crear la estructura reutilizable.

- layouts/

- assets/
